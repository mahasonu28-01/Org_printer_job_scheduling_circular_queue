Algorithm

Circular Queue Operations

The queue uses a dynamically resizing circular array. Front and Rear move around the array using modulo arithmetic; when all slots are occupied, storage expands automatically and jobs keep their FIFO order.

Enqueue(job)

if size == capacity:
    resize to 2 × capacity
    copy jobs in Front → Rear order
    set Front = 0

rearIndex = (Front + size) % capacity
buffer[rearIndex] = job
size = size + 1

Time: O(1) amortized · O(n) when resizing

Adds a new print job at the Rear. There is no fixed maximum job count because the buffer expands when full.

Dequeue()

if size == 0:
    report "Queue is empty"
else:
    job = buffer[Front]
    clear buffer[Front]
    size = size - 1

    if size == 0:
        Front = 0
    else:
        Front = (Front + 1) % capacity

    return job

Time: O(1) amortized

Removes and returns the oldest waiting job. If the queue becomes sparse, the implementation may shrink its storage.

Process Job()

if size == 0:
    report "No job to process"
else:
    job = buffer[Front]
    simulate printing job
    remove job from Front
    totalProcessed = totalProcessed + 1
    return job

Time: O(1) amortized

Simulates printing the oldest waiting job, removes it from the circular queue, and updates the completed-job count. It does not send a document to a physical printer.

Peek Front / Peek Rear

if size == 0:
    report "Queue is empty"
else:
    frontJob = buffer[Front]
    rearIndex = (Front + size - 1) % capacity
    rearJob = buffer[rearIndex]
    return requested job

Time: O(1)

Reads the next job to print or the most recently added job without removing either one.

Circular Index and Other Operations

physicalIndex(offset) =
    (Front + offset) % capacity

Get Size: return size
Is Empty: return (size == 0)
Display Queue:
    for offset = 0 to size - 1:
        show buffer[physicalIndex(offset)]
Clear Queue:
    reset buffer, Front, and size

Index / Size / Is Empty: O(1) · Display: O(n)

Modulo arithmetic wraps an index to the beginning after the last slot, so vacated slots can be reused.
